# 업무 AI 파일럿 계약 예시

아래 문서는 특정 기업 내부 데이터가 아닌, 제조·품질·고객지원 업무에서 첫 파일럿을 설계할 때 쓰는 빈 계약이다.

## 파일럿 후보

승인된 기술문서 Q&A, 검사·출하 기록의 예외 요약, 고객 이슈의 답변 초안 중 하나를 고른다. 처음부터 자동 확정이나 외부 전송까지 범위를 넓히지 않는다.

## 시작 전에 합의할 것

- 업무 소유자와 최종 승인자
- 입력 문서의 등급·버전·접근권한
- AI가 할 수 있는 일과 할 수 없는 일
- 답변에 반드시 붙을 출처와 상태
- 오류·개인정보·약관 위반이 의심될 때 멈추는 조건
- 기존 방식의 처리시간·검색시간·재작업률 기준선

## 권장 흐름

```text
요청 분류
  -> 데이터·권한 확인
  -> 승인된 자료 검색
  -> 초안 작성
  -> 출처·형식·정책 검증
  -> 담당자 검토
  -> 확정 또는 보류
```

## 첫 KPI

- 검색에 걸린 시간
- 초안 작성 시간
- 담당자 수정률
- 예외·금지 정보 누락률
- 보류 후 수동 처리 비율
- 승인 결과의 재사용률

생산성 숫자는 파일럿 전후 조건이 같을 때만 비교한다. 수치가 좋아도 품질·보안·책임소재 기준을 통과하지 못하면 승격하지 않는다.
